# Card images

Drop card photos here. Each card falls back to its animated canvas scene until
the matching file exists (see `IC.cardImages` in `lib/data.jsx`).

Recommended: ~1200×900 JPG/PNG, cool/technical imagery, main subject in the
upper half (the lower half is blurred + darkened behind the card text).

Solutions:
- `ai.jpg`        — AI-Driven Digital Transformation
- `cloud.jpg`     — Cloud & Infrastructure Modernization
- `data.jpg`      — Data Engineering & Advanced Analytics
- `it.jpg`        — Enterprise IT Modernization & Custom Development
- `program.jpg`   — Mission-Focused Program & Change Management

Products:
- `geospatial.jpg` — iCatalyst Geospatial Engine
- `semantic.jpg`   — iCatalyst Semantic Intelligence Platform
- `assistant.jpg`  — iCatalyst Vendor-Agnostic AI Assistant
